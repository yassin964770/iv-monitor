# مراقبة المحلول الوريدي (IV Monitor)

نموذج أولي لمشروع تخرج: جهاز يزن قنينة المحلول الوريدي ويحسب الكمية المتبقية ومعدل التدفق والوقت المتبقي، وينبّه قبل نفاد المحلول، ويتحكم بصمام يغلق الأنبوب ويفتحه بمحرك سيرفو.

للاختبار بالماء فقط، ولا يُستخدم على المرضى.

## الأجزاء

- ESP32
- خلية حمل 3 كغم مع مضخم HX711
- محرك سيرفو يضغط الأنبوب على قاعدة ثابتة (صمام ضغط)
- شاشة OLED بقياس 0.96 إنش (SSD1306)
- جرس تنبيه، ضوء أخضر وأحمر، زر تصفير

مخطط التوصيل: [wiring-diagram.png](wiring-diagram.png)

## المجلدات

- `iv_monitor/` برنامج الـESP32 (Arduino)
- `dashboard/` لوحة التحكم عن بعد، منشورة على GitHub Pages
- `SETUP-MQTT.md` طريقة الاتصال بالإنترنت عبر MQTT
- ملفات `*-3d.html` نماذج ثلاثية الأبعاد للتركيب

## التشغيل

1. ارفع `iv_monitor/` على الـESP32 من Arduino IDE (اللوحة: ESP32 Dev Module). المكتبات: HX711 (Bogdan Necula)، ESP32Servo، WiFiManager (tzapu)، PubSubClient، Adafruit SSD1306.
2. عند أول تشغيل يفتح الجهاز شبكة `IV-Monitor-Setup` (كلمة المرور 12345678). اتصل بها واختر شبكة الوايفاي.
3. افتح لوحة التحكم من أي مكان: تتصل بالجهاز مباشرة دون تسجيل دخول.
